# Mock API — Льготные кредиты

Мок-сервер для фронтенд-задания. Поднимается в одну команду, данные хранятся в памяти.

## Запуск

**Docker (рекомендуется):**
```bash
docker compose up --build
```

**Локально:**
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

API будет доступно на `http://localhost:8000`.  
Документация (Swagger): `http://localhost:8000/docs`

---

## Эндпоинты

### POST `/api/checks`
Загрузить документы и запустить проверку.

- **program** `(form field)` — `federal` или `regional`
- **files** `(form field, multiple)` — файлы документов

Имитирует задержку обработки ~2 секунды.

Результат зависит от имён файлов:
| Ключевые слова в имени файла | Определяется как |
|---|---|
| договор, контракт, dogovor, contract | `contract` |
| спецификация, spec, приложение | `spec` |
| счёт, счет, schet, invoice | `invoice` |
| акт, упд, накладная, act, upd | `act` |
| всё остальное | `unknown` |

**Пример запроса (curl):**
```bash
curl -X POST http://localhost:8000/api/checks \
  -F "program=federal" \
  -F "files=@договор_47.pdf" \
  -F "files=@счет_12.pdf" \
  -F "files=@акт_приемки.pdf"
```

---

### GET `/api/checks`
Список всех проверок (summary).

### GET `/api/checks/{check_id}`
Полный результат проверки по ID.

### DELETE `/api/checks/{check_id}`
Удалить проверку.

### GET `/health`
Статус сервиса.

## Сценарии для тестирования UI

Загружай файлы с разными именами, чтобы получить разные статусы:

**`approve` (зелёный)** — все обязательные типы присутствуют:
```
договор.pdf  спецификация.pdf  счет.pdf  акт.pdf
```

**`reject` (красный)** — отсутствует обязательный документ:
```
договор.pdf  счет.pdf
# нет спецификации и акта → две ошибки
```

**`manual` (жёлтый)** — только предупреждения:
```
договор.pdf  спецификация.pdf  счет.pdf  акт.pdf  scan0041.jpg
# scan0041.jpg → unknown → warning
```
